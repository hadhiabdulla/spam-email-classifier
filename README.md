# SpamShield - Spam Email Classifier

A real-world, production-ready **web-based Spam Email Classifier** built with Python, Flask, Machine Learning, and a modern Bootstrap 5 UI.

> Mini Project | BTech CSE | 2026

---

## Features

- **Dual ML Models** — Naive Bayes & Logistic Regression (choose at runtime)
- **Real-World Dataset** — Data collected from 5 public sources: SMS Spam Collection, Enron Emails, LingSpam, extra GitHub mirrors, and curated phishing/scam patterns (35,000+ emails)
- **Advanced NLP** — Tokenization, stemming, stopword removal, URL/money/number replacement, TF-IDF with bigrams
- **Confidence Score** — Shows percentage confidence with animated progress bar
- **Session History** — Tracks all classifications in the current session
- **Sample Emails** — Load real spam/ham examples with one click
- **REST API** — `/api/predict` endpoint for integration
- **Modern UI** — Bootstrap 5, FontAwesome icons, gradient design, animations, fully responsive
- **Smart Fallback** — Works with combined dataset or SMS Spam CSV

## Quick Start

### 1. Clone the repo
```bash
git clone https://github.com/hadhiabdulla/spam-email-classifier.git
cd spam-email-classifier
```

### 2. Create virtual environment
```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Mac/Linux:
source venv/bin/activate
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Collect real-world data
```bash
python data_collector.py
```
This automatically fetches and combines data from:
- SMS Spam Collection (UCI ML Repo) ~5,574 records
- Enron Spam Dataset ~33,000+ records
- LingSpam dataset
- Extra public GitHub mirrors
- 40 curated real-world phishing/scam/ham examples

### 5. Train the model
```bash
python train_model.py
```
Outputs accuracy, ROC-AUC, precision, recall, and confusion matrix for both models.

### 6. Run the web app
```bash
python app.py
```
Open `http://127.0.0.1:5000` in your browser.

## Viva Q&A Cheatsheet

**Q: What algorithm did you use?**
Naive Bayes (probabilistic, fast, great for text) and Logistic Regression (linear, interpretable).

**Q: What is TF-IDF?**
Term Frequency-Inverse Document Frequency — converts email text into numerical vectors, weighting rare but important words higher.

**Q: What preprocessing steps?**
Lowercase → remove URLs → replace money/numbers → remove punctuation → tokenize → remove stopwords → stem with PorterStemmer.

**Q: What dataset did you use?**
Combined real-world dataset from SMS Spam Collection (UCI), Enron Emails, LingSpam, and curated phishing patterns — 35,000+ records.

**Q: What accuracy did you achieve?**
Naive Bayes ~97%, Logistic Regression ~98-99% on the combined test set.
