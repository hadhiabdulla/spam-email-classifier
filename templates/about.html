About SpamShield

A Machine Learning powered spam email classifier

Objective

To automatically detect and classify email messages as Spam or Legitimate (Not Spam) using Natural Language Processing and Machine Learning techniques, reducing the manual effort required to filter unwanted emails.

How It Works
  1. Email text is cleaned and preprocessed
  2. TF-IDF converts text to numerical features
  3. ML model predicts Spam or Not Spam
  4. Confidence score is returned
Naive Bayes

Probabilistic classifier based on Bayes theorem. Fast, accurate, ideal for text classification.

Logistic Regression

Linear model for binary classification. Interpretable coefficients, great for viva explanation.

TF-IDF

Term Frequency-Inverse Document Frequency. Converts raw email text into meaningful numerical features.
